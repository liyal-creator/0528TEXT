# 社区精选 H5 通用模块兼容规范

## 1. 适用范围

本规范只约束社区精选原始 H5 的 HTML、CSS 和 JavaScript 编写方式，确保页面后续接入 Conso 通用模块时能够正常使用：

- 外部环境顶部栏和悬浮按钮。
- Conso 环境识别。
- 内容点击限制弹窗。
- 多语言通用文案。
- 首屏分享图生成。

通用模块的注入、构建、上传和客户端 PB 协议不属于原始 H5 的开发范围。

## 2. 基础 HTML 结构

原始 H5 至少应具备以下结构：

```html
<!doctype html>
<html lang="zh-Hans">
<head>
  <meta charset="UTF-8">
  <meta
    name="viewport"
    content="width=device-width, initial-scale=1, viewport-fit=cover"
  >
  <title>页面标题</title>
  <style>
    html,
    body {
      margin: 0;
      min-height: 100%;
      background: #f5f6f8;
    }

    [data-theme="dark"],
    [data-theme="dark"] body,
    body.theme-dark {
      background: #10131a;
      color: #ffffff;
    }
  </style>
</head>
<body>
  <main data-conso-share-content>
    <!-- H5 业务内容 -->
  </main>
</body>
</html>
```

必须满足：

- 文件使用 UTF-8 编码。
- 声明 `<meta charset="UTF-8">`。
- 声明移动端 viewport。
- 设置有效的 `<title>`。
- `html` 和 `body` 清除默认外边距。
- 页面不依赖通用模块也能独立展示业务内容。

## 3. 页面尺寸与响应式

页面以手机端为主要展示环境，必须满足：

- 页面宽度使用百分比、`max-width`、Flex 或 Grid 等响应式方式。
- 不得使用只适合桌面端的固定页面宽度。
- 不得出现横向滚动条。
- 内容在窄屏下不能重叠、裁切或溢出。
- 使用 `box-sizing: border-box` 控制尺寸。
- 固定在底部的业务内容需要兼容安全区：

```css
bottom: max(16px, env(safe-area-inset-bottom, 0px));
```

通用模块会在页面顶部和底部增加 UI，业务代码不得假设 `body` 中第一个或最后一个子节点一定是自己的节点。

不要使用以下脆弱选择器：

```css
body > :first-child
body > :last-child
body > div:nth-child(1)
```

应使用稳定的业务类名或 ID。

## 4. 分享图内容区域

### 4.1 必须标记截图根节点

页面主要内容根节点必须添加：

```html
<main data-conso-share-content>
  <!-- 需要进入分享图的首屏内容 -->
</main>
```

每个页面只能有一个 `[data-conso-share-content]`。

该节点应该包含页面业务内容，但不应包含：

- 页面自行实现的顶部推广栏。
- 页面自行实现的 App 内打开按钮。
- 调试面板。
- 临时提示弹窗。
- 仅开发环境使用的按钮。

### 4.2 首屏内容要求

分享图默认截取一个手机视口高度的首屏内容，因此：

- 页面标题和首要内容必须位于首屏。
- 首屏内容不能依赖用户滚动后才渲染。
- 首屏图片不能使用未加载的懒加载占位图。
- 首屏图片需要声明 `width`、`height` 或 `aspect-ratio`。
- 异步数据加载前应预留稳定尺寸，避免截图时布局跳动。
- 不得在页面加载后自动滚动。
- 不得自动弹出遮挡首屏的业务弹窗。

### 4.3 分享图标题

分享图默认使用 `<title>` 作为标题，标题应简短、明确。

如果页面标题和分享图标题不同，可以声明：

```html
<meta name="conso-share-poster-title" content="分享图标题">
```

不得通过 JavaScript 在截图前临时修改 `document.title`。

## 5. 黑夜模式兼容

分享图会在克隆页面中强制使用黑夜模式。原始 H5 的 CSS 必须支持以下状态：

```css
html[data-theme="dark"],
html[data-theme="dark"] body,
body[data-theme="dark"],
body.theme-dark {
  background: #10131a;
  color: #ffffff;
}
```

业务组件也必须提供对应样式：

```css
.content-card {
  background: #ffffff;
  color: #191919;
}

[data-theme="dark"] .content-card,
body.theme-dark .content-card {
  background: #171a22;
  color: #ffffff;
}
```

注意：

- `html`、`body` 和 `[data-conso-share-content]` 必须有明确背景色。
- 不得让上述三个节点同时保持透明背景。
- 黑夜模式不能只依赖 JavaScript 修改内联样式。
- 不得在黑夜模式中使用 `filter: invert()` 反转整个页面。
- Logo、头像和内容图片不得被全局滤镜反色。

## 6. 图片和媒体资源

### 6.1 图片 CORS

分享图由 Canvas 生成，页面图片必须满足以下任一条件：

- 图片与 H5 使用相同域名。
- 图片服务器允许跨域访问。
- 图片以内嵌 Base64 形式存在。

跨域图片响应应包含有效的：

```text
Access-Control-Allow-Origin
```

否则可能出现：

```text
Tainted canvases may not be exported
```

### 6.2 图片布局

图片必须满足：

- 设置稳定尺寸或 `aspect-ratio`。
- 设置合适的 `object-fit`。
- 首屏关键图片使用正常加载，不使用只在滚动后触发的懒加载。
- 加载失败时有占位背景，不能导致容器高度变为零。
- 不直接使用数 MB 的原图作为手机端首屏资源。

示例：

```css
.cover-image {
  display: block;
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
  background: #e8e8e8;
}
```

### 6.3 视频和特殊内容

以下内容无法保证被准确绘制到分享图：

- 播放中的视频。
- 跨域 `iframe`。
- WebGL。
- 动态 Canvas。
- DRM 媒体。

视频应提供静态封面图，并在封面上绘制播放图标。

## 7. 链接和可点击元素

### 7.1 使用标准链接

需要跳转的内容优先使用标准 `<a>`：

```html
<a href="https://t.me/example">查看频道</a>
```

通用模块会自动处理：

- Conso 内按原链接正常跳转。
- 外部环境拦截业务链接并显示 Conso 提示弹窗。

不要在业务 H5 中重复实现环境判断或限制弹窗。

### 7.2 自定义可点击卡片

如果无法使用 `<a>`，可以使用：

```html
<div role="link" tabindex="0">
  可点击内容
</div>
```

使用 `role="link"` 的节点也会被通用模块识别和限制。

自定义可点击节点必须同时支持键盘操作，不能只监听 `click`。

### 7.3 外部放行链接

隐私协议、法律条款等确实允许在外部直接打开的链接，可以添加：

```html
<a href="/privacy.html" data-conso-pass-through>隐私协议</a>
```

`data-conso-pass-through` 只能用于明确允许放行的链接，不能批量添加到业务内容。

### 7.4 不要阻断通用模块事件

不得在 `document`、`body` 或页面根节点上无条件执行：

```javascript
event.stopImmediatePropagation();
```

不得通过全局透明遮罩拦截所有点击事件。

业务事件应绑定到具体业务节点。

## 8. 保留名称

以下属性由通用模块保留，原始 H5 不得自行使用：

```text
data-conso-open-app
data-conso-share-shell
data-conso-share-entry
data-conso-restricted-modal
data-conso-dialog-cancel
data-conso-dialog-confirm
data-conso-share-preview
```

以下类名前缀由通用模块保留：

```text
conso-share-
```

业务 CSS 类名不得使用该前缀。

除 `[data-conso-share-content]`、`data-conso-pass-through` 和本规范允许的 meta 外，不得自行添加通用模块内部属性。

## 9. JavaScript 兼容约定

### 9.1 禁止覆盖桥接方法

原始 H5 不得定义、覆盖或删除：

```text
window.tokenInit
window.shareButtonVisibility
window.shareImageResult
window.ConsoH5ShareReady
```

不得读写：

```text
window.__consoEnvironmentState
window.__consoClientToken
window.__consoClientTokenReceived
window.__consoSharePendingImageRequests
window.__consoShareRuntimeLoading
```

### 9.2 禁止自行判断 Conso 环境

原始 H5 不得：

- 根据 User-Agent 判断是否在 Conso。
- 自行调用客户端 Token 方法判断环境。
- 自行探测 `conso_android` 或 `conso_ios` 后控制顶部栏。
- 自行显示 App 内打开悬浮按钮。

这些逻辑全部由通用模块负责。

### 9.3 初始化时机

业务脚本应在 DOM 可用后初始化：

```javascript
function initializePage() {
  // 初始化业务内容
}

if (document.readyState === "loading") {
  document.addEventListener("DOMContentLoaded", initializePage, { once: true });
} else {
  initializePage();
}
```

不得覆盖：

```javascript
window.onload = ...
```

如需监听页面完成，应使用：

```javascript
window.addEventListener("load", handler);
```

避免影响通用模块自己的加载监听。

## 10. 多语言兼容

通用模块会读取以下语言来源：

1. URL 参数 `language`
2. URL 参数 `lang`
3. `<html lang>`
4. 浏览器语言

业务 H5 也应优先复用 `language` 参数，不要另造含义相同的参数。

通用模块当前支持：

| 语言 | 参数示例 |
| --- | --- |
| 简体中文 | `language=zh-hans-raw` |
| 繁体中文 | `language=zh-hant-raw` |
| 英文 | `language=en` |
| 俄文 | `language=ru` |
| 阿拉伯文 | `language=ar` |

阿拉伯文业务内容应支持 RTL：

```css
html[lang^="ar"] body {
  direction: rtl;
}
```

业务文案由原始 H5 自己维护，通用模块只负责通用 UI 文案。

## 11. 样式兼容约定

### 11.1 不修改全局通用控件

业务 CSS 不得使用过宽的全局选择器修改所有按钮、图片或弹窗，例如：

```css
/* 禁止 */
button {
  width: 100%;
  height: 80px;
}

img {
  filter: invert(1);
}

[role="dialog"] {
  border-radius: 30px;
}
```

应限定在业务根节点内：

```css
.business-page .business-button {
  width: 100%;
}
```

### 11.2 层级

业务页面不应使用接近浏览器极限的 `z-index`。

推荐业务层级：

```text
普通内容：0 - 10
吸顶内容：20 - 100
业务弹窗：1000 - 9999
```

不得使用 `2147483000` 及以上层级，该范围由通用模块使用。

### 11.3 页面滚动

- 页面应使用浏览器默认纵向滚动。
- 不建议把整个页面放入自定义滚动容器。
- 不得长期设置 `html, body { overflow: hidden; }`。
- 业务弹窗关闭后必须恢复页面滚动。

## 12. 性能约定

通用模块会在页面完成后异步加载。原始 H5 必须保证首屏不会被业务代码阻塞：

- 不隐藏整个页面等待所有资源完成。
- 不在 `<head>` 中同步执行大规模计算。
- 不重复引入 `html2canvas`、`protobuf`、`qrcode` 或通用模块资源。
- 不在页面初始化时生成或上传分享图。
- 首屏图片应压缩到适合移动端的大小。
- 非首屏图片可以使用 `loading="lazy"`。
- 首屏图片应使用 `loading="eager"` 或默认加载。
- 异步渲染必须使用稳定占位尺寸。

## 13. 禁止侵入通用模块

原始 H5 中不得直接引用或复制以下代码：

- 顶部栏 HTML。
- 悬浮按钮 HTML。
- Conso 限制弹窗 HTML。
- 环境识别代码。
- Token 获取代码。
- PB 编解码代码。
- 分享图生成和上传代码。
- 通用模块 CSS。

原始 H5 只需要遵守本规范。通用能力由后续统一引入。

## 14. 开发自检清单

提交原始 H5 前必须检查：

- [ ] 文件为 UTF-8，并声明 charset。
- [ ] 页面包含移动端 viewport。
- [ ] 页面有明确且简短的 `<title>`。
- [ ] 页面不接入通用模块也能独立展示。
- [ ] 主要内容只有一个 `[data-conso-share-content]`。
- [ ] 标题和首要内容位于手机首屏。
- [ ] 手机宽度下无横向滚动和左右黑边。
- [ ] 页面无元素重叠、文字裁切或按钮溢出。
- [ ] `html`、`body` 和截图根节点具有明确背景色。
- [ ] 黑夜模式 CSS 支持 `data-theme="dark"` 和 `body.theme-dark`。
- [ ] 首屏图片尺寸稳定并支持 Canvas 跨域截图。
- [ ] 视频内容提供静态封面。
- [ ] 业务跳转优先使用标准 `<a href>`。
- [ ] 仅必要链接使用 `data-conso-pass-through`。
- [ ] 未占用 `conso-share-*` 类名和保留属性。
- [ ] 未覆盖通用桥接函数和内部变量。
- [ ] 未自行实现 Conso 环境判断。
- [ ] 未使用全局 CSS 污染所有按钮、图片和弹窗。
- [ ] 未使用超高 `z-index` 覆盖通用 UI。
- [ ] 首屏展示不依赖通用模块或长时间网络请求。
